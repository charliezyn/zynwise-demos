Automated Process

5 min review

Partner briefs submitted via structured form or email are auto-parsed by an AI agent, key fields extracted (offer type, audience segment, creative specs, compliance flags), and a structured campaign record created in Airtable ready for build

Claude API + Make + Airtable Saves 8 hrs/week

Liquid Code Generation for Braze Campaigns

15 min review

Structured campaign record triggers an AI generation pipeline that produces validated Liquid templates with personalisation rules, offer logic, fallback content and error handling — pre-checked for syntax errors before engineer review

20 min review
