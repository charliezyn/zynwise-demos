Automated Process

Adviser Onboarding & Authorisation

30 min review only

Adviser submits structured onboarding form; automation validates ASIC registration via API, cross-checks qualification documents using AI extraction, pre-populates authorisation forms and routes for sign-off via approval workflow

Power Automate + ASIC Connect API + Claude API Saves 8 hrs/week

Compliance Monitoring & Breach Reporting

15 min exception review

Scheduled automation pulls adviser activity data from Xplan via API, flags exceptions against compliance rules, auto-generates breach reports and routes alerts to the relevant supervisor for action with full audit trail

Power Automate + Xplan API + SharePoint Saves 7 hrs/week

Statement of Advice (SOA) Document Collection & Tracking

0 min for standard files

SOA submissions trigger automatic receipt confirmation, document completeness check via AI extraction, Xplan record update and status dashboard refresh. Incomplete submissions auto-request missing items from the adviser

Power Automate + Xplan API + Claude API Saves 6 hrs/week

Adviser CPD & Qualification Tracking

5 min exception review

Advisers upload CPD certificates to a structured portal; automation extracts hours and provider details, updates the CPD register in SharePoint, calculates remaining requirements and sends automated reminders to advisers falling behind

Power Automate + SharePoint + Claude API Saves 5 hrs/week

Licensee Fee Calculation & Invoicing

20 min review and approval

Automation pulls platform revenue data, applies fee schedule rules per adviser agreement, calculates charges, generates itemised invoices and sends them to adviser practices with a reconciliation summary for finance review

Power Automate + Xero + Excel Online Saves 3.5 hrs/week

Adviser Practice Data Reporting

0 min

Scheduled automation aggregates FUA, activity and client data from IconiQ, Xplan and platform feeds, populates branded report templates and distributes to relevant practice principals and internal stakeholders automatically

Power Automate + Power BI + SharePoint Saves 4.5 hrs/week
