How Profusion Group Can Save 34 Hours Per Week

Based on $75/hr average operational cost × 48 working weeks

Current Process

Automation Request Intake & Triage

45 min per request, ~8 requests/week

Business stakeholders submit automation requests via email or ad-hoc conversations. BA manually logs, categorises and prioritises each request into a tracker spreadsheet, chasing missing information back and forth.

Done by: Technology Business Analyst

Process Documentation & Flow Diagramming

3–4 hrs per process documented

BA manually transcribes notes from stakeholder workshops into Word documents and builds process flow diagrams in Visio or PowerPoint. Iterative review cycles require manual version tracking and re-sharing of files.

Done by: Technology Business Analyst

UAT Coordination & Test Case Management

2–3 hrs per UAT cycle, 2–3 cycles/week across projects

BA manually creates UAT test scripts in spreadsheets, emails them to testers, tracks pass/fail results via reply emails, consolidates feedback into a defect log and chases outstanding sign-offs one by one.

Done by: Technology Business Analyst

Automation Pipeline Status Reporting

2–3 hrs per weekly report

BA manually compiles weekly status updates across all active automation projects by pulling data from multiple trackers, emails and spreadsheets, then formats a report and distributes it to stakeholders and leadership.

Done by: Technology Business Analyst

UiPath Bot Performance Monitoring & Alerting

1 hr daily monitoring and incident logging

BA manually checks UiPath Orchestrator logs each morning to identify failed or degraded bot runs, cross-references with business users to confirm impact, then manually logs incidents and notifies technical teams via email.

Done by: Technology Business Analyst

Training Material Creation & Distribution

3–4 hrs per go-live training package

After each automation go-live, BA manually writes user guides in Word, creates PowerPoint training decks, records walkthroughs and emails materials to relevant business users. Updates after changes require the whole cycle to be repeated.

Done by: Technology Business Analyst

Python Script Output Distribution & Reporting

30–45 min per report distribution run, multiple times weekly

Python automation scripts produce data outputs and reports that BA manually downloads, formats in Excel, applies consistent branding and layout, then emails to relevant business stakeholders — often across multiple global teams.

Done by: Technology Business Analyst

Automated Process

Automation Request Intake & Triage

2 min review only

Structured intake form auto-populates a centralised pipeline board, triggers acknowledgement email to requester, assigns priority score based on effort/value fields, and notifies the BA for review. Missing fields prompt automatic follow-up to submitter.

Power Automate + Microsoft Forms + Azure DevOps Saves 5.5 hrs/week

Process Documentation & Flow Diagramming

30 min review and edit

Workshop transcripts or notes fed into an AI agent that generates a structured BRD draft and a process flow diagram. Output auto-saved to SharePoint with version control, and review task created and assigned in the project tracker.

Claude API + Power Automate + SharePoint Saves 6 hrs/week

UAT Coordination & Test Case Management

20 min oversight per cycle

Test cases auto-generated from requirement fields and distributed to assigned testers via Power Automate. Testers submit results through a structured form. Defects auto-logged in Azure DevOps, dashboard updated in real time, and sign-off reminders sent automatically on schedule.

Power Automate + Microsoft Forms + Azure DevOps + Power BI Saves 7 hrs/week

Automation Pipeline Status Reporting

0 min

Power BI dashboard automatically aggregates pipeline status, delivery milestones, hours saved metrics and backlog data from Azure DevOps and SharePoint. Scheduled weekly email with embedded summary auto-sent to stakeholders every Monday morning.

Power BI + Power Automate + SharePoint Saves 5.5 hrs/week

UiPath Bot Performance Monitoring & Alerting

10 min exception review

UiPath Orchestrator triggers are configured to auto-detect failures and SLA breaches, instantly raising an incident ticket in ServiceNow, alerting the BA and relevant technical owner via Teams notification, and logging the event with context in the incident register.

UiPath Orchestrator + Power Automate + Microsoft Teams + ServiceNow Saves 4 hrs/week

Training Material Creation & Distribution

45 min content review and approval

Go-live trigger in the project tracker automatically generates a training checklist, creates a SharePoint training page from a template pre-populated with solution metadata, notifies impacted users via Teams with links to materials, and schedules a feedback survey 2 weeks post-launch.

Power Automate + SharePoint + Microsoft Teams + Forms Saves 3 hrs/week

Python Script Output Distribution & Reporting

0 min

Python scripts push outputs directly to a SharePoint folder via API. Power Automate detects new files, applies formatting template, generates a branded PDF summary and distributes to the correct stakeholder distribution list automatically based on report type metadata.

Python + Power Automate + SharePoint + Outlook Saves 3 hrs/week
